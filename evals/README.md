# Evaluation

`make eval` runs the agent against the live OpenAI and Pinecone services on the 70
conversations in `dataset.json` and scores the replies.

```
uv run python -m evals.run_eval                      # everything, 4 cases at a time
uv run python -m evals.run_eval --category similar   # one category
uv run python -m evals.run_eval --only author_austen,similar_christie --verbose
uv run python -m evals.run_eval --baseline evals/results/<earlier>.json
uv run python -m evals.run_eval --check              # validate the dataset, no API calls
uv run python -m evals.run_eval --refresh-catalogue  # re-snapshot the index into catalogue.json
```

## Dataset

`dataset.json` is generated by `make_dataset.py`, where the cases are written with plain
Gutenberg numbers and checked against `catalogue.json`; edit the Python file and run
`python3 evals/make_dataset.py`. One entry per case:

| field | meaning |
|---|---|
| `messages` | the conversation; the last message is the user's turn |
| `ideal` | books a good answer leads with (relevance 2) |
| `relevant` | acceptable books (relevance 1) |
| `relevant_where` / `forbidden_where` | a metadata rule (`authors`, `languages`) resolved against `catalogue.json` |
| `forbidden` | books that must not be recommended: the reference of "books like X", excluded authors, books already shown |
| `expect` | `books` (default), or the fixed reply expected: `clarify`, `off_topic`, `malicious`, `too_long`, `unknown_reference`, `no_results`, `relaxed`; a list accepts any of them |

Categories: `author`, `author+language`, `language`, `era`, `theme`, `similar`, `followup`,
`constraint`, `behaviour`.

## Metrics

- **nDCG@5** of the recommended books: graded and order-aware, the headline number.
- **precision@5 / recall@5 / MRR** of the picks.
- **retrieval recall@10**: how many relevant books reached the answer step. Low retrieval
  recall with high precision means the search missed them; high retrieval recall with low
  precision means the answer step chose badly.
- **forbidden picks** and **hallucinated ids** (links to books not in the catalogue).
- **behaviour accuracy**: the expected kind of reply for non-search turns.
- **latency** p50 and p95.

A case passes when behaviour matches, nothing forbidden or unknown was recommended and, when
relevant books are defined, nDCG@5 is at least `--pass-ndcg` (0.5).

Results go to `evals/results/<timestamp>.json` (not committed). The LLM is not fully
deterministic, so expect a few cases to flip between runs; compare runs with `--baseline`.
